---------FORM ----------
Para fazer um formulario colocamos ele entre as tags de abertura/fechamento FORM
form autocomplete="off" - desliga o autocomplete dos formularios
form action="cadastro.php" - é para aonde vamos enviar os dados do formulario

URL do sumbit:
http://127.0.0.1:5500/_MODULO%2005/EXERC%C3%8DCIOS/ex025%20-%20formularios/cadastro.php?nome=iury&sobrenome=pichitelli
Tudo depois do sinal de "?" é oque foi enviado para o php 

*****************************************************************************

-------- INPUT ------------
Tipos de input:

input:text = para texto
    > name = nome do input de entrada util para o php e html
    > id = Util para o label e javascript
input:submit = para envio dos valores
    > value = nome do botão que irá aparecer no site
input:password = para senhas
    >
input:reset = para resetar os values colocados
    >

    
*****************************************************************************

-------- LABEL ------------
label = todo label tem que ter o FOR com o mesmo nome do ID do input
obs: o label é bem útil para dispositivos mobile, pois cria uma area maior clicável

*****************************************************************************

-------- METODO DE ENVIO DOS FORMULARIOS ------------
GET = Dados enviados na url, aparece na url, fácil de compartilhar (Link compatilhavel), menos seguro. Quantidade de betys limitada até 3000 bytes
    > Quando usar GET?
        - Quando os dados não são sensíveis
POST = Dados são enviados dentro do body da requisiçaõ, mais seguro (ainda dá para interceptar). Tamanho ilimitado.
    > Quando usar POST?
        - Quando os dados forem sensíveis (senha, cartão de crédito, fotos)
        - Dados acima de 3000 bytes
        - Envio de arquivos
